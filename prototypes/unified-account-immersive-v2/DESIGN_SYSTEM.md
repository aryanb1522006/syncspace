# Join-first immersive design system

## Visual idea

SyncSpace is shown as a living field of student projects. Five examples float independently and
send small signals toward the Join destination. The student remains visible as `You`, while Join is
the strongest visual anchor. Posting an idea is present but secondary.

## Tokens

- Deep forest background: `#061713`
- SyncSpace ink: `#10231f`
- Electric lime: `#d5ff55`
- Mint: `#c7f2dd`
- Lavender: `#d9d4ff`
- Coral: `#ff806b`
- White: `#ffffff`

## Typography and layout

- Font stack: Inter, Segoe UI Variable, Segoe UI, Arial, sans-serif.
- Hero headline: large editorial scale, compact line-height, no eyebrow or badge.
- Landing width: maximum 1480px with generous desktop gutters.
- Project examples use small floating labels rather than cards or dashboard tiles.
- The workspace remains white and restrained so functional screens are not overwhelmed by 3D.

## Motion

- Project nodes float with independent phases instead of following circular orbits.
- Signal points travel along curved project-to-Join paths.
- Join uses two restrained pulse rings to remain the destination.
- Pointer movement adds shallow parallax to the field.
- Scrolling gently pulls projects toward Join and reveals downstream sections through Anime.js.
- Reduced motion freezes continuous movement and removes nonessential motion hints.

## Interaction rules

- All project names, labels, buttons, forms, and emails are normal DOM elements.
- The canvas remains decorative and `aria-hidden`.
- Each project label is a real button leading into the local Join demonstration.
- Sign up, posting, and applying remain mock interactions with no production writes.
